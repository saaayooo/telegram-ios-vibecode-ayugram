# Проверка до признания функций рабочими

Статус всех сценариев устройства: **NOT RUN**. Нужны два тестовых аккаунта A (NVXGram) и B (наблюдатель), iPhone со сборкой и доступ к macOS runner/симулятору для записи UI. Не используйте реальные чувствительные переписки.

| Сценарий | Ожидаемое подтверждение |
| --- | --- |
| Сборка | `verify` PASS, полный `release_arm64` PASS; bundle `org.nvxgram.ios`, подпись и arm64 PASS; SHA исходников и run URL записаны |
| Авторизация | Первый вход, перезапуск, повторное подключение после авиарежима; аккаунт остаётся авторизованным, история догружается |
| OFF/OFF | Штатные online, typing, read receipts; ручная отметка прочтения |
| Ghost ON | Включить, закрыть и открыть приложение 3 раза; B наблюдает ≥90 секунд. По отладочному перехвату RPC нет `account.updateStatus(offline:false)`; offline присутствует |
| Typing | Печатать ≥15 секунд в личном чате/группе, набрать текст в секретном чате, начать запись; B не получает typing; запросов из ordinary local activity pipeline нет |
| Ghost OFF | Online и typing возвращаются штатно |
| Отправка | При Ghost ON отправить текст, фото и альбом. Доставка успешна, после подтверждения вызывается offline. Записать реальную длительность online у B; она ограничена сервером, не фиксируется обещанием клиента |
| Ghost без нечиталки | Прочитать личное сообщение. Записать возможный временный online из-за серверной политики чтения; этот случай не считать гарантированно скрытым |
| Оба ON, ordinary cloud chat | B отправляет обычные сообщения; A открывает/прокручивает историю и получает новые сообщения при открытом чате; read index A не растёт, B не видит прочтение. Проверить личный чат, basic group, supergroup без тем, канал |
| Нечиталка и reconnect | После просмотра выйти/перезапустить A, авиарежим→сеть. Чат на сервере остаётся unread; при открытии второго клиента A проверить read max до собственного чтения этим клиентом |
| Ручное чтение | При ON выбрать «Прочитать» в контекстном меню/свайпе списка чатов, затем «Прочитать всё». Серверный read max растёт, B видит прочтение; новые сообщения снова остаются unread |
| Выключение нечиталки | OFF и заново открыть чат: штатное автоматическое чтение возвращается; нет зацикленных retries |
| Синхронизация | Новые сообщения, edits, delete, attachments, offline delivery и read updates другого сеанса продолжают приходить без pts/seq разрывов и циклов getDifference |
| Неизвестный TTL | До загрузки cached peer TTL действует штатное чтение. После подтверждения выключенного TTL обычная история подпадает под нечиталку |
| Защищённый контент | Secret chat, view-once, исчезающее фото/голосовое, chat auto-delete ON: штатные receipts и countdown, удаление в нужный момент; контент не сохраняется обходным способом |
| Темы/комментарии | Штатное readDiscussion/readSavedHistory; UI не обещает нечиталку для них |
| Другой клиент | Прочитать A через официальный клиент; NVXGram применяет серверный read update, не откатывает его |
| Приватность | Повторить с «Последняя активность и в сети»: Все / Никто / исключения; записать разницу, не менять privacy автоматически |
| Персистентность | Все четыре комбинации настроек сохраняются после force quit/relaunch, изменения не затрагивают другой переключатель |
| UI | Settings → NVXGram содержит ровно два переключателя и пояснение. Light/dark, крупный шрифт, back navigation, русский/английский интерфейс. Записать видео симулятора и кадры по AGENTS.md; сейчас UI не подтверждён |

Для проверки RPC используйте отладочные точки/инструментированную тестовую сборку, счётчики методов без message bodies, auth keys, телефонов и access hashes. Не публикуйте MTProto-логи с личными данными. Source guards и truth-table тесты не заменяют этот план.

Запись результата: SHA сборки, Actions run URL, модель iPhone/iOS, privacy, комбинация switches, сценарий, наблюдение B, ожидаемое/фактическое, PASS/FAIL, доказательство. Любой FAIL авторизации/синхронизации блокирует установочную рекомендацию.
